# Logo TecnoShop · Mark 10 (Bolt-Aperture)

Octágono negro con rayo amarillo recortado.

## Paleta de marca

| Color  | HEX     | Uso                          |
|--------|---------|------------------------------|
| Ink    | #0A0A0A | Octágono / texto principal   |
| Yellow | #F4D03F | Rayo (acento)                |
| Paper  | #F5F2EA | Fondo claro                  |

## Archivos

| Archivo                       | Cuándo usarlo                          |
|-------------------------------|----------------------------------------|
| `tecnoshop-logo.svg`          | Logo principal sobre fondos claros     |
| `tecnoshop-logo-inverso.svg`  | Logo sobre fondos oscuros              |
| `tecnoshop-logo-amarillo.svg` | Tile amarilla (app icon, badges)       |
| `tecnoshop-lockup.svg`        | Logo + wordmark "TecnoShop" horizontal |
| `favicon.svg`                 | Favicon vectorial para el navegador    |

## Reglas de uso

- **Espacio libre:** ≥ ¼ de la altura del octágono.
- **Tamaño mínimo:** 16 px (favicon).
- **No deformar**, **no cambiar colores** salvo las versiones oficiales.
