# TecnoStore

Plantilla de e-commerce construida con Angular 17 y PrimeNG.

## Requisitos

- Node.js 18+
- Angular CLI 17

## Desarrollo

```bash
npm install
npm start
```

La app corre en `http://localhost:4200/` con recarga automática.

## Build

```bash
npm run build
```

Los artefactos se generan en `dist/tecnostore`.

## Tests

```bash
npm test
```

## Stack

- Angular 17 (standalone: false, módulos)
- PrimeNG 17 + PrimeFlex + PrimeIcons
- SCSS
